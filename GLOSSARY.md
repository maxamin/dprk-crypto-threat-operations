# Glossary

- **Attribution:** assigning activity to an actor; distinct from observation.
- **Cluster:** a vendor-defined grouping of related activity.
- **Lure:** social engineering pretext (job offer, investor, candidate).
- **Peel chain:** sequential small transfers splitting funds on Bitcoin.
- **OTC broker:** off-exchange trader used for cash-out.
- **RMM:** remote monitoring and management tool, sometimes abused for remote access.
- **Technical linkage:** an evidence-based connection between artefacts (shared address, shared code) that falls short of attribution.
- **Signing ceremony:** the scheduled process in which multisig signers approve a treasury transaction.
- **Independent verification:** each signer recomputing the transaction hash from the ticketed intent on a separate machine.
- **delegatecall:** an EVM call that runs another contract's code in the caller's storage context; a red flag in routine treasury transfers.
- **Safe Guard:** a contract attached to a Safe that can reject transactions that break a policy.
- **Dormancy:** stolen funds left idle for long periods before laundering resumes.
- **Freeze window:** the time between a theft and the first hop where an issuer, exchange or bridge can act.
- **Canary:** a harmless decoy file or value used to test detections or reveal access.
- **Inject:** a timed scenario event given to participants in a tabletop exercise.
